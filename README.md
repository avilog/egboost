EGBoost
======================

# Introduction 
The code repository including all scripts and results from my master thesis research, "EGBoost – a Generic Method to Fit Interpretable
and Trustworthy GAMs with Interactions".

Acadamic supervision was done by  Prof. Oded Margalit and Prof. Gera Weiss.


# Installation
To install, clone the repository and make sure to install all the required python modules.

XGBoost: We modified its code, so we need to build from source. Please run:
```
git submodule update --init --recursive
cd xgboost
mkdir build
cd build
cmake ..
make -j$(nproc)
```
For more details on building XGboost from source, see `build <https://xgboost.readthedocs.io/en/latest/build.html>`_.

# Description
The folder contains the following files and directories:
- *egboost.py* - Our algorithm. Currently using XGBoost as base gradient boosting model.
- *benchmark_regression_classification.py* - The file that runs all the experiments. 
Its generate the models and the following result files: accuracy_results.csv, accuracy_results_usecases.csv, feature_sparseness_results.csv, bias_variance_results.csv.
- *models* - The models trained by *benchmark_regression_classification.py*. Some of them are removed (Spline method and feature ordering experiment) as they took a lot of space.
- *xgboost* - The modified code of XGBoost.
- *generate_accuacy_sparsness_bias_tables.ipynb* - This notebook load the result files generated by *benchmark_regression_classification.py* and create the table for the thesis.
- *generate_shape_plots.ipynb* - This notebook load the models generated by *benchmark_regression_classification.py* and generate all the plots for the shape functions.
- *feature ordering experiment.ipynb* - This notebook generate the plots for the feature ordering experimets.

# Running the Experiments
The experiments can be run using the file: benchmark_regression_classification.py.
To run specific expremnts we set set their flag to True:
- *RUN_ACCURACY* - To run the accuarcy expermnts (on real and synthetic datasets)
- *RUN_FEATURE_SPARSENESS* - To run the feature sparsness expermnts (on real and synthetic real datasets)
- *RUN_BIAS_VARIANCE* - To run the bias variance expermnts (on real datasets)
- *RUN_USECASES* - To run the survival analysis (on NHANES I dataset) and monotonic constraints experiments (on California Housing)

You can choose to run just on just part of the datasets by removing datasets from the variable *DATASETS_LIST*.
